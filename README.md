# A Simple Visual Novel

A short, choice-driven visual novel developed with **Ren'Py and Python**.

This project explores interactive storytelling, branching dialogue, multiple endings, and collectible illustrations. The game is currently in the prototype stage, using placeholder assets while the core mechanics are being developed.

## Technologies

- **Ren'Py 8.5.3:** Visual novel game engine.
- **Python 3:** Game logic, variables, and persistent data.
- **Ren'Py Script & Screen Language:** Dialogue, branching narratives, and user interface development.
- **Ink & Inky:** Interactive narrative scripting language and editor by Inkle Studios, being explored for story planning.
- **Git & GitHub:** Version control and source code management.

## Planned Features

- Character portraits and dialogue system.
- Interactive choices and branching storylines.
- Multiple endings based on player decisions.
- Save, load, and continue functionality.
- Unlockable CG illustrations.
- CG gallery with persistent progress.
- Character gallery with portraits and introductions.
- Custom main menu and user interface.
- Replayable routes and alternative dialogue.

## Development

Development begins with a small playable prototype using placeholder assets.

The initial focus is on implementing and testing the gameplay systems before adding the final story, character designs, backgrounds, and illustrations.

## Running the Project

1. Download the [Ren'Py SDK](https://www.renpy.org/).
2. Clone this repository.
3. Open the Ren'Py Launcher.
4. Select the directory containing the cloned project.
5. Launch **A Simple VN**.
